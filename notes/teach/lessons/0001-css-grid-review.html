1. Vocabulary: the foundation ⏱ 1 min

The three units of a grid
track — one full row or column (strip between two lines). You define tracks.
line — the dividers, numbered from 1, created implicitly. You position items on lines.
cell — one row track crossing one column track. The smallest unit.
Key Insight A grid with N tracks on an axis has N+1 lines. You define tracks; the lines appear for free; items occupy cells (or spans of them).

2. Positioning: on lines, not cells ⏱ 2 min

You place an item by saying which line it starts on and which it ends on. It fills the cells between. Spanning is free — just move the end line out.

grid-column: 2 / 3;   /* one column  */
grid-column: 2 / 4;   /* spans two   */
grid-column: 1 / -1;  /* full width (-1 = last line) */
grid-column: 1 / span 2;  /* start at 1, cover 2 tracks */

Worked Example: grid-area shorthand

1.grid-area packs four lines: row-start / col-start / row-end / col-end.
2.grid-area: 1 / 1 / 3 / 6 → rows line 1→3, columns line 1→6.
Result: spans 2 row tracks and 5 column tracks. Both starts first, then both ends.
Trap: line 0 / start == end Lines start at 1, never 0 (0/3/0/3 fails). And start == end gives zero span. Use real distinct line numbers.

3. grid-area's double life & template-areas ⏱ 2 min

grid-area means two totally different things:

As line numbers
grid-area: 1 / 1 / 3 / 6 — four lines.
As a name
grid-area: header — only works with a grid-template-areas map on the container.

The named approach, in 3 steps:

.container {
  /* 1. SIZE the tracks */
  grid-template-rows: 100px 100px 500px 100px;
  grid-template-columns: 340px 1020px;
  /* 2. MAP the layout with names */
  grid-template-areas:
    "header  header"
    "sidebar nav"
    "sidebar article"
    "footer  footer";
}
/* 3. CLAIM each name */
.header { grid-area: header; }
Key Insight Spanning = repeating the name (across a row spans columns, down rows spans rows). . = empty cell. A spanned area must be a solid rectangle or the whole map is silently ignored.

4. Sizing tracks: repeat, fr, minmax, clamp ⏱ 2 min

  • repeat(count, size) — many same-size tracks: repeat(5, 1fr).
  • fr — a share of the leftover space. 1fr 4fr = 1/5 and 4/5. (auto = size to content, different thing.)
  • minmax(min, max) — grid-only; track flexes between bounds.
  • clamp(min, ideal, max) — global; sits at ideal, clamps at the edges.
  • min() / max() — pick smallest / largest from a list.
Trap: static vs dynamic px is static — 1px 3px = two slivers, does NOT fill. fr is dynamic — 1fr 3fr fills the width 1:3 and resizes. The ratio only "fills" with fr, never px.

5. The responsive one-liner: auto-fit / auto-fill ⏱ 2 min

grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

"As many ≥250px columns as fit, each growing to share leftover space." Browser counts using the min, then grows each to the max. No media queries. Live demo below — drag the bottom-right corner to resize and watch the column count change:

Key Insight — the reversible one auto-FIT = empty tracks collapse, items FIT/stretch to fill. auto-FILL = empty ghost tracks stay, items keep their size. Identical when full; differ only with fewer items than fit. Mnemonic: FIT = items fit, FILL = row filled with ghosts. Live visualizer.

Dynamic row count? You can't use grid-template-rows (that's for a known number). Use grid-auto-rows: 200px to size every auto-created row, or set height on the item.

6. Explicit vs implicit, and global rows ⏱ 1 min

Explicit
Tracks you define with grid-template-*.
Implicit
Tracks the browser auto-creates when items need them. Referencing a line (grid-row: 2 / 4) creates the rows to satisfy it.
Key Insight Rows are global — a row line cuts across ALL columns. The column with the most stacked items sets the row count; quieter columns span to match (e.g. a sidebar at grid-row: 2 / 4 covering two rows the other column split into).

7. Alignment: 4 properties, 2 ideas ⏱ 1 min

items vs content, self vs container
justify-items / align-items — align each item INSIDE its own cell (per-item: justify-self / align-self).
justify-content / align-content — align the whole group of TRACKS in the container (only when they don't fill it).
place-items: center — align-items + justify-items shorthand. justify- = horizontal, align- = vertical.
Trap: align-items center kills the stretch Default stretch makes an item fill its cell (the "auto-growing"). center shrinks it to content and centers it — so it stops filling, even in a tall cell. Want fill = stretch; want centered = center. (For a real logo, use justify-self, not text-align.)

8. Grid vs Flexbox: when to use which ⏱ 1 min

Flexbox
Content-first, ONE dimension (row OR column). Nav bars, button groups, centering, a card's inner stack.
Grid
Layout-first, TWO dimensions (rows AND columns). Page skeletons, dashboards, card galleries.
Real-World Connection The usual answer is both, nested: Grid for the page skeleton, Flexbox inside grid items for their content. Exactly what you built in the holy-grail mockup — Grid for regions, inner grids/flex for the content.

Retrieval Quiz — answer before checking

1. When positioning a grid item, the numbers refer to...

  • grid lines, not cells
  • grid cells by index
  • the tracks by number
  • pixels from corner
Correct. You place items between line numbers; they fill the cells between. Lines start at 1, -1 = last.

2. fr distributes which space?

  • the leftover space
  • the content space
  • the full viewport
  • the padding space
Correct. fr = a share of remaining space. auto is the one that sizes to content.

3. Which function is grid-only?

  • minmax, not clamp
  • clamp, not minmax
  • both are global
  • neither is global
Correct. minmax() is grid-only; clamp() works on any property.

4. With fewer items than fit, auto-fit will...

  • stretch items to fill
  • keep empty ghost cols
  • stack into one column
  • hide the extra cells
Correct. auto-fit collapses empties so items stretch. auto-fill keeps the ghost columns.

5. Why does align-items: center stop filling?

  • it sizes item to content
  • it shrinks the whole cell
  • it removes the row gap
  • it disables the grid row
Correct. center sizes the item to content and centers it; default stretch fills. It shrinks the item, not the cell.

6. Use Grid (over Flexbox) when the layout is...

  • two-dimensional layout
  • one row of buttons
  • centering one item
  • a single nav bar
Correct. Grid = layout-first, two dimensions. Flexbox = content-first, one dimension.
